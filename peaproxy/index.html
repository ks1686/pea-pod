Get Started

Maximize whatever you already pay for, fall back to keys, and treat Ollama / LM Studio / llama.cpp / vLLM / OpenRouter-free / OpenCode Zen as first-class — then expose one OpenAI-shaped, one Claude-shaped, and one Responses local endpoint that coding tools already speak.

Status: CLI + localhost UI at 127.0.0.1:8317. Tagged v1.4.0 includes API keys + free/local providers (llama.cpp, vLLM, Jan, GPT4All, NIM, Workers AI, SambaNova, Ollama Cloud), POST /v1/responses, and subscription OAuth (Claude, Codex, Gemini/Antigravity, xAI, Kimi, Meta Muse) with a ban/ToS warning — prefer official API keys. Requires Go 1.22+ for go install.

Go install (tagged v1.4.0)

go install github.com/ks1686/peaproxy/cmd/peaproxy@v1.4.0

@latest currently resolves to the same tag. Installs to ~/go/bin/peaproxy — put that directory on PATH.

Linux binary (amd64)

curl -Lo peaproxy.tar.gz https://github.com/ks1686/peaproxy/releases/latest/download/peaproxy_1.4.0_linux_amd64.tar.gz tar -xzf peaproxy.tar.gz && sudo mv peaproxy /usr/local/bin/

Also on the release: linux/darwin/windows amd64 + arm64 (zip on Windows).

First serve writes ~/.config/peaproxy/config.yaml if missing.

Run

peaproxy --version
peaproxy serve
peaproxy auth login --provider anthropic
# UI + OpenAI/Claude wires at http://127.0.0.1:8317/  (auth is ToS/ban risk)

Features

📡

Live catalog

Models come from live ListModels — no hand-maintained allowlist. Hide is listing-only; optional pin/rename overlays (UI and peaproxy catalog). Routing is unchanged.

🔌

Local wires

OpenAI /v1/chat/completions, Claude /v1/messages (true SSE), Codex /v1/responses (native OAuth passes tools through), image-out /v1/images/generations, and embeddings /v1/embeddings.

🖥️

CLI + localhost UI

No macOS tray. Accounts, Catalog, Showcase, Clients, Health, Request log, and Settings in the browser on loopback. Showcase generates for image_out models and can try embeddings. First-run onboarding CTAs; Settings shows bind, LAN, and secret-backend status.

🔑

Keys, free, and local

Ollama (local or Cloud), LM Studio, llama.cpp, vLLM, Jan, GPT4All, Groq, Cerebras, Google AI Studio, xAI, Hugging Face, NVIDIA NIM, Cloudflare Workers AI, SambaNova, Anthropic/OpenAI/OpenRouter keys, OpenCode Zen, custom OpenAI-compat. Presets show env var names, never values.

🪪

Subscription OAuth

v1.4.0 includes Claude, Codex, Gemini/Antigravity, xAI, Kimi, and Meta Muse login. Ban/ToS risk; prefer API keys. See Security.

🔁

Failover

429/401 and retryable error bodies move to the next account; policies round-robin (default), fill-first, and sticky. Cooled accounts are not re-hit. Usage is persisted next to the config as usage.json.

🧰

Harness presets

peaproxy clients show for Cursor, Claude Code, OpenCode, Pi, Codex, Amp, Continue, Cline (YAML / /v1 polish), plus clients verify.

Security

ToS / ban liability. Subscription OAuth through a local proxy (Claude Pro/Max, ChatGPT/Codex, Gemini/Antigravity, xAI, Kimi, Meta Muse) may violate a provider’s terms and can result in account suspension or ban. You proceed at your own risk. PeaProxy authors are not liable for bans, suspensions, lost subscriptions, lost data, or any other damages. The official, lower-risk path is an API key. Details: docs/OAUTH.md.

Default bind is loopback. Binding 0.0.0.0 requires --allow-lan and a non-empty admin token. Never log secrets; the opt-in request log is redacted. OpenCode Zen free models may train on prompts — see catalog privacy notes.
